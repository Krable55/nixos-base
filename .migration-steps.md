# sops-nix → agenix Migration Steps

## Phase 3: Migration Testing

### Step 1: Test agenix deployment
After completing the manual setup, test on one host:

```bash
# Test deployment to media-center
colmena apply --on media-center

# Check if agenix secrets are working
ssh media-center.local "sudo systemctl start agenix-test"
ssh media-center.local "sudo journalctl -u agenix-test --no-pager"
```

### Step 2: Create Tailscale authkey secret
```bash
# Replace with your actual Tailscale authkey
echo "tskey-auth-YOUR-ACTUAL-KEY-HERE" | agenix -e tailscale-authkey.age
```

### Step 3: Update host configurations to use agenix Tailscale

**Option A: Update existing configuration.nix**
Change line 35 in `configuration.nix`:
```nix
# FROM (sops):
authKeyFile = lib.mkIf config.sops.secrets.tailscale-authkey.path;

# TO (agenix):
authKeyFile = config.age.secrets.tailscale-authkey.path;
```

**Option B: Use new tailscale-agenix module**
Add to host configs that need Tailscale:
```nix
imports = [
  ../modules/tailscale-agenix.nix
];

custom.tailscale-agenix.enable = true;
```

### Step 4: Deploy and test Tailscale migration
```bash
# Deploy to one host first
colmena apply --on media-center

# Verify Tailscale is working
ssh media-center.local "sudo tailscale status"
```

### Step 5: Complete migration to all hosts
```bash
# Deploy to all hosts
colmena apply

# Verify all hosts have Tailscale working
```

## Phase 4: Cleanup (after successful migration)

### Step 6: Remove sops-nix dependency
1. Remove `sops-nix` from flake.nix inputs
2. Remove `sops-nix.nixosModules.sops` from all modules lists
3. Delete `modules/sops.nix`
4. Remove sops references from `base.nix`
5. Run `nix flake update` and deploy

### Step 7: Update documentation
Update any documentation to reflect agenix usage instead of sops-nix.

## Rollback Plan
If anything goes wrong:
1. Revert configuration changes
2. Deploy previous working config: `colmena apply`
3. Check logs: `journalctl -u tailscaled`
