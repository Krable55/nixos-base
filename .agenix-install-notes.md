# Agenix Secrets Management Guide

## Step 1: Update flake.lock
Run this to pull in agenix:
```bash
nix flake update
```

## Step 2: Install agenix CLI
**Recommended approach** (temporary shell):
```bash
nix --extra-experimental-features "nix-command flakes" shell github:ryantm/agenix -c agenix <command>
```

**Permanent installation:**
```bash
nix profile install github:ryantm/agenix
```

## Step 3: Collect SSH host keys
Run these commands and update secrets.nix with the output:

```bash
echo "Copy these keys into secrets.nix:"
echo ""
echo "media-center = \"$(ssh-keyscan -t ed25519 media-center.local 2>/dev/null | cut -d' ' -f2-)\";"
echo "builder = \"$(ssh-keyscan -t ed25519 builder.local 2>/dev/null | cut -d' ' -f2-)\";"
echo "networking = \"$(ssh-keyscan -t ed25519 networking.local 2>/dev/null | cut -d' ' -f2-)\";"
echo "powerball = \"$(ssh-keyscan -t ed25519 powerball.local 2>/dev/null | cut -d' ' -f2-)\";"
echo "trader = \"$(ssh-keyscan -t ed25519 trader.local 2>/dev/null | cut -d' ' -f2-)\";"
```

## Organized Secrets Structure
Our secrets are now organized in directories:
```
secrets/
├── global/              # Available to all hosts
│   ├── tailscale-authkey.age
│   └── test-secret.age
├── hostname/service/    # Host-specific service secrets
└── trader/supabase/     # Example: Supabase secrets for trader
    ├── admin-password.age
    ├── jwt-secret.age
    └── ...
```

## Step 4: Create secrets with organized paths

**Global secrets** (all hosts can access):
```bash
echo "tailscale-key" | agenix -e secrets/global/tailscale-authkey.age
```

**Host-specific service secrets:**
```bash
# Supabase secrets for trader host
echo "admin-pass" | agenix -e secrets/trader/supabase/admin-password.age
echo "jwt-secret" | agenix -e secrets/trader/supabase/jwt-secret.age
echo "anon-key" | agenix -e secrets/trader/supabase/anon-key.age
echo "service-key" | agenix -e secrets/trader/supabase/service-role-key.age
echo "db-pass" | agenix -e secrets/trader/supabase/postgres-password.age
echo "secret-base" | agenix -e secrets/trader/supabase/secret-key-base.age
echo "vault-key" | agenix -e secrets/trader/supabase/vault-enc-key.age

# faasd secret for networking host
echo "auth-pass" | agenix -e secrets/networking/faasd/basic-auth-password.age
```

## Step 5: Test agenix deployment
Deploy to one host to test:
```bash
colmena apply --on media-center
```

## Re-encrypting Secrets
After adding new hosts or updating keys:
```bash
nix --extra-experimental-features "nix-command flakes" shell github:ryantm/agenix -c agenix -r
```

## Helper Functions in secrets.nix
Our `secrets.nix` uses helper functions for easy management:

```nix
# Host-specific service secrets
mkServiceSecrets "trader" trader "supabase" [ 
  "admin-password" "postgres-password" "jwt-secret"
  "anon-key" "service-role-key" "secret-key-base" "vault-enc-key"
]

# Global secrets available to all hosts  
mkGlobalSecrets "tailscale" [ "authkey" ]
```

## Adding New Hosts/Services

1. **Add host key to secrets.nix**
2. **Add service secrets using helper functions**
3. **Re-encrypt**: `agenix -r`
4. **Create secret files**: `mkdir -p secrets/host/service && agenix -e ...`

## Useful Commands

**List all secrets:**
```bash
find secrets/ -name "*.age" -type f | sort
```

**Edit existing secret:**
```bash
agenix -e secrets/trader/supabase/admin-password.age
```

**View secret names defined in secrets.nix:**
```bash
nix --extra-experimental-features "nix-command flakes" eval --impure --expr 'builtins.attrNames (import ./secrets.nix)'
```

## Generating Supabase Secrets

### 1. JWT_SECRET (32+ characters)
```bash
# Generate secure JWT secret
openssl rand -base64 32
# Example result: "super-secret-jwt-token-with-at-least-32-characters-long"
```

### 2. ANON_KEY & SERVICE_ROLE_KEY
Use Supabase's official JWT generator or create JWTs manually:

**Option A: Manual JWT Creation**
```bash
# Install JWT CLI tool
npm install -g jsonwebtoken-cli

# Generate ANON_KEY (role: anon, 5-year expiration)
jwt-cli encode --payload '{"role":"anon","iss":"supabase","iat":1641910000,"exp":1799766000}' --secret "YOUR_JWT_SECRET"

# Generate SERVICE_ROLE_KEY (role: service_role, 5-year expiration)  
jwt-cli encode --payload '{"role":"service_role","iss":"supabase","iat":1641910000,"exp":1799766000}' --secret "YOUR_JWT_SECRET"
```

**Option B: Use Supabase's Online JWT Generator**
Visit: https://supabase.com/docs/guides/self-hosting/docker#generate-api-keys

### 3. Other Required Secrets
```bash
# POSTGRES_PASSWORD (database password)
openssl rand -base64 16

# SECRET_KEY_BASE (32+ characters)
openssl rand -base64 32

# VAULT_ENC_KEY (32+ characters) 
openssl rand -base64 32
```

### 4. Creating All Supabase Secrets at Once
```bash
# Generate JWT secret
JWT_SECRET=$(openssl rand -base64 32)
echo "$JWT_SECRET" | agenix -e secrets/trader/supabase/jwt-secret.age

# Generate other secrets
openssl rand -base64 16 | agenix -e secrets/trader/supabase/admin-password.age
openssl rand -base64 16 | agenix -e secrets/trader/supabase/postgres-password.age
openssl rand -base64 32 | agenix -e secrets/trader/supabase/secret-key-base.age
openssl rand -base64 32 | agenix -e secrets/trader/supabase/vault-enc-key.age

# Generate JWT-based API keys (use the JWT_SECRET from above)
# ANON_KEY and SERVICE_ROLE_KEY need to be generated using JWT tools
```

**⚠️ Important**: ANON_KEY and SERVICE_ROLE_KEY must be valid JWTs signed with your JWT_SECRET. Use Supabase's official generator or JWT libraries to ensure compatibility.

## Using 1Password for Secret Management

### Automated Approach (Recommended)

**Option 1: Bash Script (Fully Automated - 1Password + agenix)**
```bash
# Create and configure Supabase instance with automatic agenix export
./scripts/supabase/supabase-1password-setup.sh trader      # Creates "Supabase Trader Instance" 
./scripts/supabase/supabase-1password-setup.sh powerball   # Creates "Supabase Powerball Instance"
./scripts/supabase/supabase-1password-setup.sh networking  # Creates "Supabase Networking Instance"
./scripts/supabase/supabase-1password-setup.sh production  # Creates "Supabase Production Instance"

# The script automatically:
# 1. Creates 1Password item: "Supabase <Hostname> Instance"
# 2. Generates secure passwords for all fields
# 3. Generates proper JWT tokens (ANON_KEY, SERVICE_ROLE_KEY) 
# 4. Updates 1Password with all secrets including JWTs
# 5. Exports all secrets to agenix: secrets/<hostname>/supabase/*.age
```

**Option 2: Node.js Script (JWT Generation Only)**
```bash
# First create the item manually, then generate JWTs
op item create --template scripts/supabase/supabase-template.json --vault Private --title "Supabase Trader Instance"
./scripts/supabase/supabase-jwt-generator.js "Supabase Trader Instance"
```

### Manual Approach

#### 1. Create secrets in 1Password from template
```bash
# Create item from template with generated passwords
op item create --template scripts/supabase/supabase-template.json --vault Private --title "Supabase Trader Instance"

# Get the item ID for reference
ITEM_ID=$(op item list --format json | jq -r '.[] | select(.title=="Supabase Trader Instance") | .id')
```

### 2. Generate JWT tokens and update 1Password
```bash
# Get JWT secret from 1Password
JWT_SECRET=$(op item get "$ITEM_ID" --field jwt_secret)

# Generate JWT tokens
ANON_KEY=$(jwt encode --payload '{"role":"anon","iss":"supabase","iat":1641910000,"exp":1799766000}' --secret "$JWT_SECRET")
SERVICE_ROLE_KEY=$(jwt encode --payload '{"role":"service_role","iss":"supabase","iat":1641910000,"exp":1799766000}' --secret "$JWT_SECRET")

# Update 1Password with JWT tokens
op item edit "$ITEM_ID" anon_key="$ANON_KEY" service_role_key="$SERVICE_ROLE_KEY"
```

### 3. Export secrets from 1Password to agenix
```bash
# Create script to export all secrets to agenix
#!/bin/bash
ITEM_ID="<your-item-id>"

# Export each secret to agenix
op item get "$ITEM_ID" --field admin_password | agenix -e secrets/trader/supabase/admin-password.age
op item get "$ITEM_ID" --field postgres_password | agenix -e secrets/trader/supabase/postgres-password.age  
op item get "$ITEM_ID" --field jwt_secret | agenix -e secrets/trader/supabase/jwt-secret.age
op item get "$ITEM_ID" --field anon_key | agenix -e secrets/trader/supabase/anon-key.age
op item get "$ITEM_ID" --field service_role_key | agenix -e secrets/trader/supabase/service-role-key.age
op item get "$ITEM_ID" --field secret_key_base | agenix -e secrets/trader/supabase/secret-key-base.age
op item get "$ITEM_ID" --field vault_enc_key | agenix -e secrets/trader/supabase/vault-enc-key.age
```

### 4. Automated workflow script
```bash
#!/bin/bash
# supabase-secrets-sync.sh - Complete 1Password to agenix workflow

# Create 1Password item
echo "Creating 1Password item from template..."
op item create --template secrets/trader/supabase/template.json --vault "Personal"
ITEM_ID=$(op item list --format json | jq -r '.[] | select(.title=="Supabase Trader Instance") | .id')

# Generate and update JWT tokens

# Export to agenix
echo "Exporting secrets to agenix..."
op item get "$ITEM_ID" --field admin_password | agenix -e secrets/trader/supabase/admin-password.age
op item get "$ITEM_ID" --field postgres_password | agenix -e secrets/trader/supabase/postgres-password.age
op item get "$ITEM_ID" --field jwt_secret | agenix -e secrets/trader/supabase/jwt-secret.age
op item get "$ITEM_ID" --field anon_key | agenix -e secrets/trader/supabase/anon-key.age
op item get "$ITEM_ID" --field service_role_key | agenix -e secrets/trader/supabase/service-role-key.age
op item get "$ITEM_ID" --field secret_key_base | agenix -e secrets/trader/supabase/secret-key-base.age
op item get "$ITEM_ID" --field vault_enc_key | agenix -e secrets/trader/supabase/vault-enc-key.age

echo "Supabase secrets created in 1Password and exported to agenix!"
```
